M5 CARDPUTER ADV · ESP32-S3

A compact keyboard bridge for the Cardputer ADV. Your quarters open first; Wi-Fi is optional for solo play.

Processor & memory
ESP32-S3FN8, 8 MB flash, 512 KB on-chip SRAM. This build does not use PSRAM.
Display
1.14-inch IPS LCD, ST7789V2, 240 × 135 pixels. No touchscreen.
Controls & sensing
56-key keyboard, BMI270 6-axis motion sensor, infrared emitter, and battery sensing.
Connections & extras
2.4 GHz Wi-Fi, Bluetooth LE, USB-C, microSD slot, microphone, speaker, 3.5 mm audio jack, 1750 mAh battery, and expansion bus.

Pocket Fleet currently uses the display, keyboard, onboard flash, and Wi-Fi. M5Stack Cardputer ADV specifications

Optional Cap LoRa-1262

Your Cardputer ADV can carry this cap. It adds an SX1262 LoRa radio (868–923 MHz) through SPI and a GNSS receiver through UART. It has its own external LoRa antenna and built-in GNSS antenna.

The current Pocket Fleet image uses Wi-Fi for fleet play; LoRa and GNSS support are not implemented yet. The cap has no separate Pocket Fleet installer. Attach the LoRa antenna before powering the cap. M5Stack Cap LoRa-1262 specifications

FIRST START

The CYD opens your quarters first, with no Wi-Fi scan or RGB LED alerts. Choose Start Solo Ship to play locally. To find fleets later, open Dock → Connect to Wi-Fi. After joining an ordinary network, enter the IP address of the computer running npm start on the CYD. The browser installer does not need a firmware toolchain.

The game host still runs on a computer. The larger board currently centers the 320 × 240 game controls on its 480 × 320 display.
